# 内容与设计分开验收

先实际查看原片与结果。下面用于检查，不作为默认生成 Prompt 的附加限制。

## A. 内容

- 主要人物是否可辨认，关键动作、接触和故事物件是否保留。
- 表情、嘴形、视线是否改变；如闭嘴变露齿，明确指出，不因画面好看就说完全一致。
- 构图是否偏离原片，区分背景概括与主要叙事变化。原配方允许简化的无关人物/杂物，不按旧版“所有后台细节必须保留”误判。
- 用户明确要求的文字逐字检查；自动生成的标题检查拼写、可读性和是否虚构事实。不能把伪字当正确字。
- 原生尺寸、预览尺寸与后续放大分别记录，不声称原片级细节恢复。

## B. 设计

- **主次**：脸和关键动作是否先被看见，还是背景人物、瓶罐与网点同样抢眼？
- **背景概括**：是否形成有层次的印刷色块，而非把每个照片细节等权描一遍？
- **排版**：标题与人物和负空间是否组成整体，是否只是给照片贴了一块牌子？大字不天然更好，小字也不天然更高级。
- **配色**：是否有清楚的主色、纸底和点缀关系，避免整张均匀黄黑发闷；也不把某次成功的红色固定为所有作品模板。
- **网点**：是否疏密有节奏，脸、衣服与空白能否区分，避免全画面等密度噪点。
- **印刷整体感**：轮廓、平涂、字与旧纸是否像同一件作品，而不是照片上盖纹理。

启用版式参考模式时再检查：

- **主体锚点**：第一视觉焦点是否仍是原片主要人物、动作或故事物件。
- **标题安全区**：标题是否落在真实可用的负空间，没有压住脸、手、接触关系或关键物件。
- **裁切安全**：平台比例或出血是否造成断头、断手、误删物件或关系变化。
- **阅读路径**：标题、主体和辅助信息是否形成一条清楚路径，而不是平均抢夺注意力。
- **缩略图识别**：社交发布图缩小时，主体和核心标题是否仍能辨认；该检查不适用于普通单张原片转换。

两条分别报告。内容基本保留不等于设计好；设计有吸引力也不等于人物完全没变。BACKSTAGE MAGIC 案例的可借鉴点是主次、背景概括、排版节奏及网点疏密，不是其全部内容变化。

用户对具体结果的明确认可属于该次作品的审美验收。已经认可后，不因代理对标题大小、配色偏好或版式节奏的主观看法自动重试；仍应如实记录拼写错误、缺失关键道具、异常肢体或与用户明确要求冲突等客观问题。

## 修正与停止

有关键内容错误或明确设计失败时，在用户生成授权范围内最多定向修正一次，另存 Prompt 与结果并标明已偏离原文。不要为修正一个问题自动补一长串背景、位置和配色限制。

仍不符合时停止自动重试，报告具体问题；不把明显错误淡化成轻微纹理差异。单纯个人偏好不触发无限追图，保留结果让用户选择。

## 交付

- prompts/01-final.md：实际传给工具的完整文本。默认版本应与原始配方逐字节一致。
- selection.md：源图路径和尺寸、实际结果文件和尺寸、原文/定制/重试模式、用户要求的变化、内容检查、设计检查、已知偏差。
- 预览另存，默认展示一张成品；非用户要求不做拼图或样机。

用户未给标题时不要先在工作记录拟标题再塞回默认 Prompt；生成后记录实际标题即可。读取最终文件并核对，不以工具成功代替视觉验收。不擅自发布或上传照片。

结构验证和原文一致性测试只能证明封装未改写配方，不能证明出图质量。视觉回归须使用同一原片与完整原 Prompt 实际生成，记录模型/工具和输入差异；结果存在随机性。
