# 明确请求下的最小修改

仅在用户要求改变默认配方时读取。默认路径不使用本文件改写 Prompt。

## 操作方式

先复制完整 original-prompt.md，再修改与用户要求直接相关的段落。保留其他原文、顺序和语气；不要把长配方压缩成摘要，不添加本次照片所有人物和背景的清单。在独立的 changes.md 记录用户要求、修改段落及原因，不把记录传给模型。

## 请求与修改范围

| 用户明确要求 | 允许修改的内容 |
|---|---|
| 纯插画、不加字 | 替换封面标题、辅助刊物文字、排版及最终输出中要求新增文字的条款；清除其他段落对 headline 的强制要求。其余插画、油墨、轮廓和网点原文不动 |
| 只有标题 | 移除辅助刊号、价格、栏目等要求，保留标题和其他原文 |
| 指定标题或语言 | 只替换标题生成和语言条款，逐字采用用户文案；不同时指定用户未要求的位置或色彩 |
| 少做旧 | 只调整纸张磨损、折痕和污渍段落；不要连带降低轮廓、色块或网点力度 |
| 指定油墨/配色 | 只改冲突的颜色条款；不要擅自移植参考图人物或构图 |
| 严格保留背景/构图 | 只针对用户指定对象补强保留要求，并消解与简化/移除条款的冲突；告知可能降低封面设计自由度 |
| 保留指定现场文字 | 替换与之冲突的源文字移除条款，列出确切文字；不能承诺生成模型逐字保真 |

“不要加字”默认指不新增刊物文字，不等于自动删除用户明确要求保留的现场文字。有实际冲突时只问关键问题。

## 不做的改写

- 不从头重新写 Input / Preserve / Palette / Rendering 模板替代原文。
- 不因看到暖灯或蓝衣服就额外写死一套油墨或“禁止大面积红色”。
- 不把标题限定在某一面镜子或右上角，除非用户明确指定。
- 不默认移除原配方已有的背景简化空间，也不为模仿某次好看的结果自行允许改笑容或移动主体。
- 不借“参数控制”改变原始 Prompt 未被用户要求改变的部分。

参考图只在用户要求使用时传入。需要角色说明时保持最短，并记录新增文本；参考的配色或布局不得默默覆盖用户原片。
